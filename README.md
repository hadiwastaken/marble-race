# marble race

## PROJECT NAME: MARBLE RACE ##
* BASICALLY THIS project is name by a member of hackclub and this  is a 3D printed marble race track made for understanding the Onshape software and understanding complex designing.

* **DAY 1 & 2 :**
* SO IN DAY 1 I setup the Onshape software and watch tutorials to understand the software also the guide is very helpful to explore the software and on day 2 I started with guide and try to make squares. 
* **DAY 3 & 4 :**
*  On those days I make circles and basic tracks and try to extrude things bcuz the guide is quite hard to understand I have to make extra efforts and asks questions from AI .
