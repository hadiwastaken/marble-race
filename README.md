## PROJECT NAME: MARBLE RACE ##
**what is it:**

* So basically, it is CAD design made on on shape and it is a simple marble race or run designed for understanding how a CAD design is made.
 **FEATURES:**

  * SO the features are quite simple here is a list of features : .
  * firstly, it is very small easily sits on your table or for artwork in yoyr frame
  * also it features a funnel with tilted edges supported by a pillar.
  * I use a spiral for track and made it wide enough to crawl for marble.
  * and a proper base for sturcture
  * also it features a catching marble section where marble is dropped from the spiral.

* ## PARTS :##
*  SPIRREL
*  SPIRRAL PILLAR (TO SUPPORT SPIRALL)
*  BASE
*  BALL COLLECTOR
*  FUNNEL
*  PILLLAR FOR FUNNEL TO SUPPORT
